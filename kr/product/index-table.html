    TROCHOID INDEX UNIT

    INDEX TABLE SYSTEMS

    고하중 정밀 이송을 위한 대구경·슬림형 인덱스 테이블 시스템

    고객이 요구하는 외경과 내경, 탑재 하중, 정밀도 조건에 맞춰 설계할 수 있는 주문형 인덱스 테이블입니다. Trochoid 구동 구조를 기반으로 안정적인 반복 정밀도와 내구성을 확보합니다.

    제품 개요 구성 적용 분야
    DPD Original Trochoid Drive

    고하중 회전 이송, 대형 워크 반송, 정밀 포지셔닝이 필요한 장비에서 고객 사양에 맞춘 회전 유닛을 구현합니다.

    • 고객사 요구 외경·내경 대응 가능
    • 대구경·슬림형 구조 설계
    • 고하중·고정도 이송 공정 특화
    • Trochoid Index Unit, Trochoid Bearing Unit 대응
    SYSTEM CONFIGURATION

    Index Table 구성

    KEY POINTS

    적용 포인트

    정밀 이송

    반복 정밀도와 하중 조건을 함께 검토해 회전 이송 품질을 안정화합니다.

    장비 최적화

    워크 크기와 주변 구조에 맞춰 외경·내경·높이를 조정합니다.

    국산화 대응

    해외 Index 대체 및 장비 맞춤형 설계 실적을 기반으로 대응합니다.
