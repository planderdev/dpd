# CSS structure

Connected files are intentionally grouped by role:

- tokens.css: design tokens, font faces, global html/body/selection defaults
- icons.css: Remix Icon font and icon classes
- swiper.css: Swiper base styles
- foundation.css: reset, accessibility, generic utility, keyframe animation
- layout.css: header, footer, navigation, sitemap, shared page frame
- pages.css: main and sub page content sections
- board.css: board, gallery, archive/download, contact form styles
- vendors.css: third-party plugin styles other than Swiper and Remix Icon
- components.css: current DPD site components and interaction styles

Archived source CSS lives in archive/legacy and is not linked from HTML.
